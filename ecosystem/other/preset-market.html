预设仓库 (Preset Market) ​

字数
954 字
阅读时间
5 分钟

此插件提供了 ChatLuna 预设仓库的一站式下载，搜索服务。

ChatLuna 预设仓库地址：https://github.com/ChatLunaLab/awesome-chatluna-presets

欢迎各位提交自己的预设到预设仓库，丰富 ChatLuna 的生态。

配置 ​

前往插件市场，安装 chatluna-preset-market 插件。

启用插件即可。

使用 ​

参考下面的 下载预设 命令，下载你心仪的预设到本地。 下载后参考 切换预设，切换到你下载的预设。

命令 ​

下载预设 ​

下载一个预设到本地。

以下为命令格式：

powershell
chatluna.preset.download <presetName:string>

以下为参数说明：

  • presetName: 预设的名称。

以下为例子：

聊天记录
U
User
chatluna.market.download 小帅
B
Bot
下载预设 小帅 成功，快使用 chatluna.preset.list 查看吧

搜索预设 ​

基于输入的关键词，搜索预设仓库中的预设。

以下为命令格式:

powershell
chatluna.market.search <query:string>

以下为参数说明:

  • query: 关键词。

以下为例子:

聊天记录
U
User
chatluna.market.search 小帅
B
Bot
以下是关于预设 小帅 的结果：名称：小帅关键词: 小帅当前页数：(1/1)

列出预设 ​

列出所有预设仓库可用的预设。

以下为命令格式：

powershell
chatluna.market.list -l <limit:number> -p <page:number>

以下为可选参数：

  • -l,--limit: 指定返回预设的数量上限，默认为 3。
  • -p,--page: 指定返回预设的页数，默认为 1。

刷新预设 ​

刷新预设仓库中的预设列表。

以下为命令格式：

powershell
chatluna.market.refresh

以下为例子：

聊天记录
U
User
chatluna.market.refresh
B
Bot
刷新预设仓库成功，快使用 chatluna.preset.list 查看吧

上传预设 ​

上传一个预设到预设仓库。

由于 ChatLuna 的预设仓库是基于 GitHub 的，我们无法直接上传预设，所以需要你手动上传。

上传后，请在 预设仓库 中提交一个 Pull Request，我们会及时审核。

以下为命令格式：

powershell
chatluna.market.upload

以下为例子：

聊天记录
U
User
chatluna.market.upload
B
Bot
非常抱歉，由于我们使用 GitHub 作为预设仓库，请有需要上传预设的用户前往此仓库提交 Pull Request: https://github.com/ChatHubLab/awesome-chathub-presets
